Overview

What is CyberShield ML?

Cyber attacks are growing in frequency and sophistication. This project tackles the problem of automated threat detection by training machine learning models on network traffic data to identify malicious activity — reducing the need for manual analysis and enabling faster, more accurate threat response.

Problem
Traditional rule-based systems fail to detect novel cyber threats. Manual analysis is too slow and error-prone at scale.
Solution
Train ML models on labeled network traffic data to automatically classify connections as normal or a specific type of attack.
Input
Network traffic features — packet size, protocol type, connection duration, flags, byte counts, and more.
Output
Classified threat label — Normal, DoS, Probe, R2L, U2R — with evaluation metrics.
Workflow

ML Pipeline

The system follows a structured machine learning pipeline — from raw network data to final threat classification — with careful attention to preprocessing and feature quality.

1

Data Collection

Network traffic dataset loaded containing labeled records of normal connections and various attack types. Each record captures dozens of connection-level features.

Pandas · CSV Dataset
2

Data Preprocessing

Raw data cleaned and prepared — handling missing values, encoding categorical features like protocol type and service, and normalizing numerical features to a common scale.

Pandas · Label Encoding · StandardScaler
3

Feature Extraction

Relevant features selected from the dataset that are most informative for distinguishing attack types from normal traffic — reducing noise and improving model performance.

Feature Selection · Scikit-learn
4

Model Training

Two ML models trained on the processed dataset — Random Forest and Support Vector Machine (SVM). The dataset is split into training and testing sets for fair evaluation.

Random Forest · SVM · Train/Test Split
5

Threat Classification

Trained models classify each network connection record into its correct category — Normal traffic or one of several attack types — in real time.

Multi-class Classification

Algorithms

ML Models Used

Two powerful classification algorithms were trained and compared to find the best approach for cyber threat detection.

🌲
Random Forest
An ensemble learning method that builds multiple decision trees and merges their results. Handles high-dimensional data well, resistant to overfitting, and naturally ranks feature importance — making it highly effective for network intrusion detection.
Ensemble · Decision Trees · Feature Importance
📐
Support Vector Machine
A powerful classifier that finds the optimal hyperplane to separate threat classes in high-dimensional feature space. Particularly effective when clear margins between normal and attack traffic exist, with strong generalization ability.
SVM · Hyperplane · Kernel Trick
Evaluation Metrics
Accuracy
Percentage of total predictions the model got correctly out of all records.
Precision
Of all connections flagged as threats, how many were actually threats — minimizes false alarms.
Recall
Of all actual threats, how many did the model successfully catch — minimizes missed attacks.
F1-Score
Harmonic mean of Precision and Recall — the overall balanced measure of model performance.
